# Dota 2 地图更换器

这是一个仅用于更换 Dota 2 本机地形文件的 Windows 图形工具。

界面采用纯 WPF / WinForms 绘制的原创暗黑奇幻 RTS 视觉系统：蓝黑石墨背景、黑铁与暗金双层边框、魔法蓝主操作和紫色目标状态。皮肤不包含第三方 UI 框架、额外字体、外部纹理或 Blizzard / Warcraft III 素材；地图原图、四列卡片布局和所有地图替换流程保持不变。程序自身的教程、确认、成功、警告和错误提示也统一使用同一套 RTS 风格。

## 发布方式

项目同时生成安装版和免安装版。

安装版：

```text
dist\Dota2MapSwitcherSetup.exe
```

安装器默认使用当前用户的 `%LOCALAPPDATA%\Programs\Dota2MapSwitcher`，不需要管理员权限。点击“浏览…”时只需选择上一级位置，安装器会自动追加并创建 `Dota2MapSwitcher` 子文件夹；如果选中的本身已是 `Dota2MapSwitcher` 或现有安装目录，则不会重复追加。手动输入时仍视为完整安装路径。“创建桌面启动快捷方式”可由用户勾选；桌面不会创建卸载快捷方式。开始菜单保留启动和卸载入口，Windows“已安装的应用”也保留卸载项。

免安装版：

```text
dist\Dota2MapSwitcher-Portable.zip
dist\Dota2MapSwitcher-Portable\Dota2MapSwitcher.exe
```

分享时可直接发送 ZIP；解压后必须让 `Dota2MapSwitcher.exe` 和 `使用说明.txt` 保持在同一文件夹中。整个文件夹可以移动或改名，但不能只移动 EXE；移动或改名后需要在自动替换模式中重新复制 Steam 启动参数。EXE 已内嵌主脚本、11 张地图图片、中文文案和应用图标，启动时不会显示命令提示行。

免安装版会校验同目录的说明文件和目录内容。单独移动 EXE 或把额外文件放入该文件夹时，程序会拒绝运行且不会解压运行资源。如需从桌面启动，请为文件夹内的 EXE 创建桌面快捷方式。

工具不会复制或备份 VPK。运行资源临时解压到程序文件夹内的隐藏目录 `.runtime`；隐藏目录 `.data` 保存当前替换记录、普通选择、自动模式配置、会话所有权和自动日志。正常关闭会恢复地图、删除当前替换记录和运行资源，但会保留小型配置文件。数据不会写到程序文件夹之外。

## 两种模式

普通模式保持原有流程：手动选择地图并替换，Dota 2 退出时不恢复；只有用户关闭工具或主动取消替换时才恢复。

程序启动后先显示模式选择页；选择“普通模式”或“自动替换模式”后点击“下一步”，再进入共用的大地图卡片选择页。两种模式的首次教程和普通模式退出警告都可选择“不再提示”，设置保存在程序自己的 `.data` 目录中。地图选择页右上角的“重置教程”会重新启用两种模式的教程，并立即显示当前模式教程；不会重置普通模式退出警告。

自动替换模式需要分别选择“我已拥有”地图和目标地图，再点击“激活自动替换”。激活只保存配置，不会在 GUI 中修改任何 VPK。复制 Steam 启动参数到 Dota 2 的“属性 → 通用 → 启动选项”后，Steam 才会在以后启动游戏时调用本工具；工具在启动真正的 Dota 2 之前替换地图，等待本次 Dota 2 会话真正结束，再恢复原版并退出。

启动参数根据当前 EXE 的真实绝对路径生成，不依赖安装目录或安装注册表项：

```text
"C:\实际路径\Dota2MapSwitcher.exe" --auto %command%
```

标准顺序始终是：`[本工具 EXE] [本工具参数] %command% [Dota 2 原有参数]`，整条启动项只能有一个 `%command%`。例如用户原来的启动参数为：

```text
-perfectworld -novid -console
```

添加本工具后应填写为：

```text
"C:\实际路径\Dota2MapSwitcher.exe" --auto %command% -perfectworld -novid -console
```

路径可包含空格和中文。复制按钮只复制本工具的标准前缀，不读取或修改 Steam 配置。复制成功提示会明确显示粘贴位置：`Steam 客户端 → 库 → 右键 Dota 2 → 属性 → 通用 → 启动选项`。已有 Dota 2 参数必须由用户保留在 `%command%` 后面，不要放在工具 EXE 或 `--auto` 前后。免安装目录移动或改名后，GUI 会检测已保存路径与当前路径的差异并提示重新复制；普通模式不会受影响。点击“取消激活”后，即使 Steam 启动参数仍然保留，工具也会完整转发 Dota 2 命令及后续参数，不修改地图。也可以直接删除本工具的 Steam 启动参数；Steam 不再调用工具，自然不会进行自动替换。

普通模式当前目标和自动模式目标分别保存。普通模式临时更换地图不会覆盖自动配置。普通模式已经成功替换时拥有优先权：Steam 启动的自动实例只放行 Dota 2，不替换也不恢复；反过来，自动会话正在运行时 GUI 可以打开，但普通替换会暂时禁用。

## 图片选择逻辑

1. 完全退出 Dota 2。
2. 启动工具，选择“普通模式”，点击“下一步”。
3. 第一次点击地图图片，将它标记为“我已拥有”。
4. 再点击另一张地图图片，将它标记为“替换为”并立即执行更换；此时程序会自动读取 Steam 配置定位 Dota 2，未找到时才请用户选择目录。
5. 当前已有“替换为”时，点击另一张地图图片会先恢复上一组，再更换为新目标。
6. 再次点击当前“替换为”图片，会取消目标选择、恢复这一组文件并清除替换记录；“我已拥有”仍保留，方便继续选择。
7. 如需改选“我已拥有”，先取消当前“替换为”，再点击当前“我已拥有”取消它，然后重新选择。
8. 替换后保持工具打开，再启动 Dota 2；退出游戏后关闭工具，确认“关闭并恢复”，程序会自动恢复并删除记录。
9. 点击“上一步”时，如果替换正在生效，必须先确认并成功恢复，才能返回模式选择页。
10. 程序仍会记住上一次的普通模式选择；本次启动第一次进入普通模式且 Dota 2 未运行时，会沿用并重新应用有效的目标选择。主动取消目标会清除这项目标记忆。

主窗口使用“模式选择 → 地图选择”的两步页面，不再同时显示模式页签或常驻教程文字。默认地形不会出现在地图卡片中。

## 自动恢复

- 每次更换前，程序都会先对上一组文件再次执行一次文件名交换，使其恢复原状。
- 随后通过一个短暂的临时文件名互换本次选择的两个 VPK；不会复制 VPK 内容。
- `.data\active-swap.json` 只在替换生效期间记录当前安装目录、两个文件名、对应地图名和会话所有者。
- `.data\preferences.json` 记录上一次选择的两张地图和 Dota 2 地图目录。
- `.data\auto-mode.json` 独立记录自动模式开关、自动地图、Dota 2 地图目录和上次生成启动参数时的 EXE 路径。
- `.data\ui-settings.json` 独立记录两种模式教程和普通模式退出警告是否继续显示；旧版本没有这些字段时全部默认显示。
- `.data\terrain-session.json` 配合 Windows Named Mutex 记录当前所有者（`Normal` 或 `Auto`）、会话 ID、PID 和进程启动时间；只有匹配的所有者能够恢复。
- `.data\auto-launch.log` 记录无 GUI 自动流程的替换、启动、等待与恢复结果。
- 取消当前“替换为”图片，只对当前文件对再次交换，并删除记录。
- 正常关闭程序也会执行相同恢复并删除记录；如果 Dota 2 仍在运行，程序会阻止关闭。
- 如果重命名过程中出现错误，程序会根据已完成的阶段立即逆向改回。

如果程序崩溃或被意外中断，`.data` 记录会保留。退出 Dota 2 并重新启动工具后，程序会先自动恢复地图，再删除记录。恢复完成前不要删除程序文件夹。

安装版卸载时，可使用开始菜单中的“卸载”或 Windows“已安装的应用”。卸载器会先调用地图恢复流程；只有恢复成功才会删除安装目录、替换记录、快捷方式和卸载项。如果 Dota 2 仍在运行或恢复失败，卸载会停止并保留恢复信息。安装包 `Dota2MapSwitcherSetup.exe` 是用户自行保存的下载文件，卸载器不会删除它。

免安装版删除时，先退出 Dota 2，再正常关闭工具，最后删除整个 `Dota2MapSwitcher-Portable` 文件夹。不要通过任务管理器强制结束，也不要在替换生效时断电或直接删除文件夹。

请不要在软件外手动改名或移动相关 VPK。Steam 更新或“验证游戏文件完整性”也可能恢复地图文件。

Dota 2 地图目录通常为：

```text
<Steam库>\steamapps\common\dota 2 beta\game\dota\maps
```

## 自检

地图逻辑自检：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Dota2TerrainSwitcher.ps1 -SelfTest
```

GUI 加载测试：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -STA -File .\Dota2TerrainSwitcher.ps1 -UiSmokeTest
```

自检只在系统临时目录创建微型测试 VPK，不会修改真实游戏文件。
